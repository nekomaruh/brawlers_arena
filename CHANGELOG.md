# Changelog

All notable changes to this project will be documented in this file.

## [0.9.5] - 2017-04

### Added
- Initial release of Brawlers Arena
- Multiple playable characters (8 unique fighters)
- Various battle maps (5 different environments)
- Scoring and ranking system
- Joystick/gamepad support for Raspberry Pi 3B+
- Sound effects and background music
- Character selection menu
- Map selection menu
- Pause functionality
- High score tracking

### Technical Details
- Built with Pygame
- Optimized for Raspberry Pi 3B+
- Python 3.5 compatible
- Custom sprite animations
- Real-time collision detection
