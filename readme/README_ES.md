# Brawlers Arena

Brawlers Arena (2017) - Game Remake 

## Descripción

Un videojuego de luchas en 2D desarrollado con Pygame. El juego permite seleccionar personajes, mapas y competir en batallas por puntos.

## Características

- Múltiples personajes jugables
- Varios mapas de batalla
- Sistema de puntuación
- Controles de joystick
- Música y efectos de sonido

## Requisitos

- Python 3.5+
- Pygame
- Numpy

## Instalación

```bash
pip install pygame numpy
```

## Uso

```bash
python PLAY.py
```
