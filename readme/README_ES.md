# Brawlers Arena

Brawlers Arena (2017) - Remake del Juego

Un videojuego de luchas en 2D desarrollado con Pygame.

## Acerca del Proyecto

**Brawlers Arena** es un proyecto universitario originalmente creado en la **Universidad Católica del Norte** en 2017. El proyecto fue inicialmente desarrollado para Raspberry Pi 3B+ con soporte de joysticks.

A partir de 2026, este proyecto está en proceso de **refactor/remake** para mejorar la eficiencia y agregar funcionalidades que faltaron en su tiempo. El objetivo es modernizar el código base manteniendo la experiencia de juego original.

## Requisitos

- Python 3.5+
- Pygame
- Numpy

## Instalación

### 1. Clonar el repositorio
```bash
git clone https://github.com/nekomaruh/brawlers_arena.git
cd brawlers_arena
```

### 2. Crear un entorno virtual
```bash
python3 -m venv venv
```

### 3. Activar el entorno virtual

**En macOS/Linux:**
```bash
source venv/bin/activate
```

**En Windows:**
```bash
venv\Scripts\activate
```

### 4. Instalar dependencias
```bash
pip install pygame numpy
```

### 5. Ejecutar el juego
```bash
python PLAY.py
```

## Uso

Una vez que el juego esté en ejecución, usa tu teclado o joystick para:
- Navegar por los menús
- Seleccionar tu personaje
- Elegir tu mapa de batalla
- Luchar contra otros jugadores
